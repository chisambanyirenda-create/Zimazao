Build a completely separate secret CEO Control Room web app for a farming platform called Zimazao. This is NOT the public app — this is a private command center only the CEO can access. It connects to the same Supabase database as the public app so all data is live and real.

1. TECH STACK
- Next.js frontend
- Node.js + Express backend
- Same Supabase database as Zimazao public app
- Dark premium design — deep black and navy with gold accents
- This app has NO connection or link to the public Zimazao app

2. LOGIN & SECURITY
- Single login page — no signup, no registration
- Admin username and password hardcoded in environment variables
- After login show: "Welcome back, CEO 👑" with live Zambia time
- Session expires after 8 hours
- 3 wrong password attempts = locked for 30 minutes
- All routes protected — redirect to login if not authenticated

3. CONTROL ROOM DESIGN
- Full dark theme — black background, deep navy panels, gold (#F59E0B) accents
- Fixed sidebar with Zimazao logo + CEO label + navigation icons
- Top bar: CEO title, live Zambia clock, notifications, logout
- All stats use skeleton loaders then animate counting up
- Mobile responsive

4. LIVE REVENUE DASHBOARD
- Revenue cards: Today / This Week / This Month / All Time
- Commission earned total
- Active Pro subscribers count
- Total users, Total farmers, Total buyers
- Revenue line chart — last 30 days
- Top 5 selling crops (bar chart)
- Top 5 earning farmers
- Recent 20 transactions table

5. USER MANAGEMENT
- Full table of all users with search and filters
- Click user → see full profile, all listings, all orders, scan history
- Actions per user: Ban, Suspend (set days), Unsuspend, Upgrade to Pro free, Send warning, Delete account
- Banned users see "Your account has been suspended. Contact support." on Zimazao

6. LISTINGS MANAGEMENT
- See all listings across the app
- Approve or reject new listings
- Feature a listing (pins to top of marketplace)
- Remove any listing instantly
- Filter by status, crop type, location

7. DISEASE SCAN INTELLIGENCE
- All scans from all users
- Most common diseases chart
- Most affected crops chart
- Most affected provinces map
- Export data as CSV

8. ANNOUNCEMENTS
- Send push notification to all users / only farmers / only buyers / specific user
- Schedule announcements for future date and time
- Full history of sent announcements

9. SPONSOR MANAGEMENT
- Add agro-dealer sponsors with logo, products, target diseases
- Activate / deactivate sponsors
- See impression count per sponsor

10. APP SETTINGS (no code needed)
- Commission rate (default 3%)
- Pro plan price in ZMW (default 80)
- Free plan listing limit (default 3)
- Free plan scan limit (default 5)
- Maintenance mode toggle
- All saved to app_settings table in Supabase

11. SECRETS TO ADD IN REPLIT
SUPABASE_DATABASE_URL = (same postgresql:// string as Zimazao)
ADMIN_USERNAME = (choose your own secret username)
ADMIN_PASSWORD = (choose your own strong password)
JWT_SECRET = (same long random string as Zimazao)

This app must never be linked from the public Zimazao app. No search engine should index it. Add robots.txt with noindex. The URL is only known by the CEO.
